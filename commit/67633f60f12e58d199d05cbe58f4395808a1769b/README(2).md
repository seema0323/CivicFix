# CivicFix

CivicFix is a simple web platform for the Omnikon 2026 problem statement **Omni_SmartCity_2 — Citizen Reporting and Tracking of Civic Issues**.

## Features
- Report potholes, garbage, broken streetlights, water leakage and other issues
- Store reports locally in the browser
- Generate a report ID
- Track Reported / In Progress / Resolved issues
- Filter reports by status
- Responsive UI for mobile and desktop

## Tech
HTML, CSS and JavaScript. No backend is required for this first-round prototype.

## Run
Open `index.html` in a browser, or use VS Code Live Server.
